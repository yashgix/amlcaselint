# Keyword baseline failures on the gold set

Generated by `demo.py --failures`. A miss is a gold quote in an order where the baseline flagged nothing for that category. A false hit is a flagged sentence in an order the gold set does not label with the category. Scoring is per order, so a category counted as hit may still flag the wrong sentence (see evidence recall in the README). Sentences are clipped to 300 characters. Labels are the frozen v1 gold set. The Lone Star (18845) independent testing false hit stands. A proposal to label it positive was rejected on 15 Nov 2026, because the sentence summarises the OCC's own earlier action in a separate section, not FinCEN's Determinations.
